# Security

Report vulnerabilities privately by DM to [@labkittrade on X](https://x.com/labkittrade). Don't open a public issue for them.

Include the affected instruction, how to reproduce it, and what an attacker gains. We'll reply as soon as we can and credit you when a fix ships, unless you'd rather stay anonymous.
